# Security Policy

Transcript Sidecar is designed to be local-first and dependency-free.

## Reporting a security issue

Please do not publish sensitive security details in a public issue before a fix is available.

Until a dedicated security contact is published, report issues through the repository owner's private contact channel or Chrome Web Store support contact listed for the extension.

## Scope

Security-relevant reports include:

- unexpected transmission of transcript or browsing data
- permission escalation
- remote code execution or remote-code loading
- cross-site data exposure
- unsafe handling of YouTube page content

The project intentionally does not include analytics, advertising SDKs, or third-party runtime JavaScript dependencies.

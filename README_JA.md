# Transcript Sidecar

[English](README.md) | [日本語](README_JA.md)

YouTube動画の文字起こし(トランスクリプト)をコピー・整形・エクスポートするための、プライバシー重視の小さなManifest V3 Chrome拡張機能です。

**現在のバージョン: 0.4.1**
**発行者: Tokumaru Labs**

> アカウント登録不要。トラッキングなし。広告なし。開発者運営の文字起こしサーバーもありません。

## 機能

- Chromeのサイドパネルで開く
- **日本語・英語の表示切り替え**に対応(ヘッダーの**JP** / **EN**からいつでも変更可能)
- 現在再生中のYouTube動画から利用可能な字幕トラックを読み取る
- ワンクリックの**全文コピー**(字幕特有の不自然な改行を除去)
- 字幕の文言はそのままに、読みやすいように段落分けを行う**読みやすいコピー**
- タイムスタンプ付きコピー
- 動画タイトル・元URL・字幕の言語・段落整形済みの文字起こしを含むMarkdownとしてコピー
- 読みやすい文字起こしを`.txt`としてダウンロード
- `.md`としてダウンロード
- 文字起こしのタイムスタンプをクリックしてYouTube動画をシーク
- アカウント不要
- アナリティクスなし
- 広告なし
- 開発者運営のバックエンドサーバーなし
- サードパーティのランタイムJavaScript依存なし

## v0.4.0での変更点

- サイドパネルのヘッダー(更新ボタンの隣)に**JP** / **EN**の言語切り替えを追加。
- 拡張機能側が管理するUI文言 — タグライン、各ボタン、状態表示、トースト、エラー、診断情報パネル、フッター、アクセシビリティ用ラベル — が選択した言語に追従するように変更。
- 言語の切り替えは即時反映。ページの再読み込みも、字幕の再取得も発生しない。
- 選択した言語はセッションをまたいで保持される。初回起動時はブラウザの設定に従い、日本語環境では日本語、それ以外では英語で表示。
- 字幕本文、動画タイトル、動画URL、YouTube由来の字幕トラックラベルは翻訳しない。
- 新しい権限の追加、外部ライブラリの追加、字幕取得戦略の変更はいずれもなし。

## v0.4.1での変更点

- 2つのtimed-text経路が字幕を返さなかった場合、現在の動画ページにすでに存在するrequest metadataを使い、YouTubeの文字起こしパネル用データを静かに取得できるように変更。
- 字幕取得のために説明欄を展開したり、YouTube側の文字起こしパネルを開く・閉じる・クリックする処理を削除。
- すべてのsilent経路が失敗した場合は、YouTubeページを動かさず、ローカルの診断情報付きでfail closedする。ユーザー自身がすでに開いている文字起こしパネルは、読み取り専用で参照する場合がある。
- 新しい権限、外部サービス、ランタイム依存、開発者運営バックエンドはいずれも追加していない。

## UI言語

ヘッダーにコンパクトな**JP** / **EN**の切り替えがあります。選択中の言語はハイライト表示され、`aria-pressed`によって支援技術にも伝わります。

- **初回起動時** — `navigator.languages` / `navigator.language`から判定します。ブラウザが日本語を優先している場合は日本語、それ以外は英語になります。
- **保持方法** — 選択内容は`localStorage`の`transcriptSidecar.uiLanguage`キーに保存され、サイドパネルを開き直した際に復元されます。拡張機能のオリジンに保存されるため、追加のChrome権限は不要で、外部へ送信されることもありません。
- **適用範囲** — 翻訳の対象は拡張機能自身が表示する文言のみです。動画タイトル、動画URL、字幕本文、YouTubeから取得した字幕トラックラベルは、常に受け取ったまま表示されます。そのため、英語UIに日本語字幕(またはその逆)という組み合わせは仕様どおりの挙動です。

## プライバシーと権限

この拡張機能が要求する権限は以下のみです。

- `scripting` — 対応するYouTubeページ上で、プレイヤー/字幕情報の読み取りと動画のシークを行うため、範囲を限定したコードを実行する。
- `sidePanel` — Chromeのサイドパネルに文字起こしインターフェースを表示する。
- YouTube限定のホストアクセス:
  - `https://www.youtube.com/*`
  - `https://youtube.com/*`
  - `https://m.youtube.com/*`

`<all_urls>`のような広範な権限は要求していません。

この拡張機能は、現在再生中のYouTube動画に紐づく字幕リソースを取得します。文字起こしテキストが開発者運営のアプリケーションサーバーへ送信されることはありません。

プライバシーポリシーの全文は[PRIVACY.md](PRIVACY.md)を参照してください。

## ローカルへのインストール

1. リリースZIPを、恒久的に使用するフォルダへ展開する。
2. Chromeで`chrome://extensions/`を開く。
3. **デベロッパーモード**をONにする。
4. **パッケージ化されていない拡張機能を読み込む**をクリックする。
5. 展開した`transcript-sidecar-v0.4.1`フォルダを選択する。
6. 字幕のあるYouTube動画を開く。
7. **Transcript Sidecar**拡張機能のアイコンをクリックする。
8. 表示言語を変えたい場合は、ヘッダーの**JP** / **EN**を選択する。
9. **全文をコピー**または**読みやすくコピー**を選択する。

## 出力形式

### 全文書き起こし

字幕セグメント特有の不自然な改行を除去し、ひとつながりの連続した文字起こしを生成します。この拡張機能は文言の要約や書き換えを行いません。

### 読みやすい書き起こし

タイミングの間隔、経過時間、文末の句読点、段落の長さを手がかりに段落分けを行います。テキスト自体は空白の正規化を除いてそのまま保持されます。

### タイムスタンプ付き書き起こし

字幕の各キューを1行ずつ、タイムスタンプ付きで保持します。

### Markdown

動画タイトル、元URL、字幕トラック情報、および段落整形済みの読みやすい文字起こしを含みます。

## 字幕取得戦略

この拡張機能は、以下の方法を順番に試行します。

1. 拡張機能のコンテキストから、YouTubeのtimed-textエンドポイントを利用(`json3`、XML/SRV、WebVTT)
2. 同じtimed-textリクエストを、YouTubeページのコンテキストから実行
3. 現在の動画ページにすでに存在するrequest metadataから、YouTubeの文字起こしパネル用データをsilent取得
4. ユーザーがすでに開いているレガシー文字起こしパネルを読み取り専用で確認
5. レガシーな`ytd-transcript-*`マークアップに依存しない、ユーザーがすでに開いている表示中の文字起こしパネルの読み取り専用スキャン

この多段階のアプローチを採用しているのは、YouTube内部の字幕まわりの挙動が動画ごとに異なり、また時間の経過とともに変化しうるためです。

## 現在の制限事項

- YouTubeが字幕を提供している動画のみサポートしています。
- 字幕のない動画を音声から文字起こしすることはありません。
- 段落整形はヒューリスティックな方法によるものであり、意図的に外部のAIサービスを使用していません。
- YouTubeはドキュメント化されていないページ/プレイヤー内部の仕様を変更することがあるため、今後もメンテナンスが必要になる場合があります。
- ライブ配信では、字幕が利用可能になるまで安定した文字起こしが得られない場合があります。

## 開発思想

Transcript Sidecarは、「小さなツールが役に立つのであれば、トラッキングやサブスクリプション、不要な権限を裏に隠すことなく、それを共有できるはずだ」というシンプルな発想から始まりました。

このプロジェクトが目指しているのは、次のような姿を保ち続けることです。

- 小さいこと
- 監査可能であること
- 依存関係がないこと
- 権限について明示的であること
- ローカルファーストであること
- 巧妙さより有用性を優先すること
